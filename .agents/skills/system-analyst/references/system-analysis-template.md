# Шаблон системного анализа

Используй, если в проекте нет подходящего шаблона. Сохраняй обязательные разделы
1–5 и трассировку; дополнительные подразделы заполняй по применимости.
Повторяй блок интеграции для каждой внешней системы. Если интеграций нет,
явно укажи это. В черновике неизвестное связывай с Q-NN; при финализации убирай
незаполненные подсказки. Не создавай контракты или поля ради заполнения шаблона.

Сначала показывай черновик в чате. Отделяй проверенные факты, согласованные
решения, предложения и временные допущения. Для входных требований без ID
введи устойчивые локальные обозначения и укажи их источник.

Все схемы оформляй только в блоках `mermaid`: процессы — `flowchart`,
взаимодействия — `sequenceDiagram`, состояния — `stateDiagram-v2`,
данные — `erDiagram`. Схемы компонентов, взаимодействий и данных согласуй с описанными контрактами.
Если схема не нужна, достаточно текста и таблиц.
