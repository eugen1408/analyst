# Шаблон эпик-спецификации

Используй этот шаблон для файла `00-epic.md` при декомпозиции большой фичи.
Каждая дочерняя часть создаётся по обычному [шаблону спецификации](spec-template.md) и ссылается на этот файл.

Используй имеющийся текст задачи и аналитику. ID в трекере необязателен.
Сохраняй ID требований и критериев приёмки; новые назначай последовательно.
Все схемы оформляй только блоками `mermaid` (`flowchart`, `sequenceDiagram`,
`stateDiagram-v2`, `erDiagram`), согласованными с текстом. Пустые подсказки
при финализации замени содержанием, ссылкой Q-NN либо причиной неприменимости.
Копируй только применимые подразделы; обязательные верхнеуровневые разделы сохраняй.
